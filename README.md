# 赛事状态检查工具

一个用于分析投注赛事状态并自动生成快捷语的工具，支持中英韩三种语言。

## 功能特性

### 1. 赛事状态检查
- **未结算赛事（Status = 0）**
  - 自动判断赛事是否已经开始（基于UTC+8时区）
  - 如果赛事未开始：生成"赛事未开始"的快捷语
  - 如果赛事已开始：生成"提交至相关单位"的快捷语

- **已结算赛事（Status = 1/16/17）**
  - 自动生成"提交至相关单位"的快捷语

### 2. 时区转换
- 自动将UTC+0时间转换为UTC+8时区进行比对
- 显示UTC+8时区的赛事开始时间和当前时间

### 3. 多语言快捷语
自动生成三种语言的快捷语：
- 🇨🇳 中文
- 🇬🇧 English
- 🇰🇷 한국어

### 4. 定时提醒
- 每9分钟自动弹出提醒通知
- 显示赛事信息和三语快捷语
- 分析数据后自动启动

### 5. 便捷操作
- 一键复制快捷语到剪贴板
- 清除功能重新开始
- 美观的用户界面

## 使用方法

### 1. 打开工具
在浏览器中打开 `event-status-checker.html` 文件

### 2. 粘贴JSON数据
将投注数据JSON复制并粘贴到文本框中

### 3. 输入群组名称（可选）
在"群组名称"输入框中输入群组名称，当赛事已开赛时会显示在快捷语中

### 4. 点击分析
点击"🔍 分析数据"按钮

### 5. 查看结果
工具会显示：
- 赛事详细信息
- 当前状态
- 群组名称（如果赛事已开赛）
- 三种语言的快捷语

### 6. 复制快捷语
点击快捷语右上角的"复制"按钮，即可复制到剪贴板

### 7. 自动提醒
- 分析后会自动启动9分钟定时提醒
- 提醒通知会在右上角弹出
- 包含完整的三语快捷语

## JSON数据格式

工具需要包含以下字段的JSON数据：

```json
{
  "Selections": [
    {
      "SelectionStatus": 0,  // 0=未结算, 1/16/17=已结算
      "StartEventDate": "2025-12-02T17:06:50Z",  // UTC+0时间
      "EventName": "赛事名称",
      "LeagueName": "联赛名称",
      "SportName": "运动类型",
      "Team1Name": "队伍1",
      "Team2Name": "队伍2",
      "Translations": {
        "EventName": "이벤트명",
        "LeagueName": "리그명",
        "SportName": "스포츠명"
      }
    }
  ]
}
```

## 状态说明

| 状态值 | 说明 | 处理逻辑 |
|--------|------|----------|
| 0 | 未结算 | 检查赛事是否开始 |
| 1 | 已结算 | 生成提交快捷语 |
| 16 | 已结算 | 生成提交快捷语 |
| 17 | 已结算 | 生成提交快捷语 |

## 快捷语模板

### 赛事未开始（status=0）
```
中文：
[赛事名称]
尚未开赛，注单会在赛事结束后尽快结算。 - Sunny

English：
[Event Name]
Event hasn't/haven't started, related bet(s) will be settled afterward. - Sunny

한국어：
[이벤트명]
아직 경기가 시작되지 않았습니다. 베팅은 경기 종료 후 가능한 한 빨리 정산됩니다. - Sunny
```

### 赛事已开始（status=0）
```
中文：
[赛事名称]
[群组名称]（如果有输入）
set pls

English：
[Event Name]
[Group Name]（如果有输入）
set pls

한국어：
[이벤트명]
[그룹명]（如果有输入）
set pls
```

### 已结算（status=1/16/17）
```
中文：
【已结算赛事】
赛事：[赛事名称]
状态：已结算
请提交至相关单位处理。

English：
[Settled Event]
Event: [Event Name]
Status: Settled
Please submit to relevant department.

한국어：
[정산된 이벤트]
이벤트: [이벤트명]
상태: 정산됨
관련 부서에 제출하십시오.
```

找到以下代码段并修改：

```javascript

function generateQuickResponse(data, isEventStarted, isSettled) {
    // ... 在这里修改快捷语模板
}
```

## 注意事项

1. **时区转换**：工具会自动将JSON中的UTC+0时间转换为UTC+8进行比对
2. **定时提醒**：提醒会每9分钟触发一次，直到页面关闭或清除数据
3. **浏览器兼容性**：建议使用现代浏览器（Chrome、Firefox、Safari、Edge）
4. **数据安全**：所有数据处理都在本地浏览器中进行，不会上传到服务器
